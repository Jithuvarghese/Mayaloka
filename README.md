# Mayaloka

Curated anti-tarnish jewellery — modern treasures wrapped in old Indian magic.

## Homepage mockups

Static, single-file HTML/CSS/JS previews — no build step, no framework. Placeholder color blocks stand in for real product photography.

```
/mockups
  /v1-signboard/index.html   — signboard-led, current mockup
```

Each variant folder is a self-contained deploy target (e.g. for Vercel), so multiple design directions can stay live side by side for client review.
