# Mayaloka

Curated anti-tarnish jewellery — modern treasures wrapped in old Indian magic.

## Homepage mockups

Static, single-file HTML/CSS/JS previews — no build step, no framework. Placeholder color blocks stand in for real product photography.

```
/mockups
  /v1-signboard/index.html   — signboard-led: heavy hero frame, stamped badges, most literal nod to the logo
  /v2-editorial/index.html   — editorial/minimal: type-led hero, frame used once and subtly, quiet luxury
  /v3-bazaar/index.html      — bazaar collage-forward: story/collection grid up higher, more texture/layering, marquee ticker
  /v4-split/index.html       — split-screen: fixed left nav/hero panel + scrolling right column, horizontal collection rail, inline product list
```

Each variant folder is a self-contained deploy target (e.g. for Vercel), so multiple design directions can stay live side by side for client review.
